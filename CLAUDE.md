# Mundo dos iPhones (front)

Antes de qualquer tarefa, leia `docs/PLANO-MUNDO-DOS-IPHONES.md`. Ele tem as regras de negócio, as telas de cada perfil e a ordem de trabalho. Comece pela seção 0, que fala de repositório novo, só do front.

O protótipo `docs/prototipo/proto-iphone.html` é a referência de telas, textos e cálculos. Abra no navegador e use "Ver como" para trocar de perfil. Não copie a estrutura do código dele.

- O Geovane fala português, de forma informal. Responda em português.
- Stack: Vue 3 + Vite + TypeScript, com componentes próprios (sem Nuxt UI).
- Dinheiro sempre com máscara BRL (4.000,00).
- Os cálculos de lucro, juros, repasse e recebimento ficam em funções puras, com testes que conferem os exemplos da seção 7 do plano.
- Trabalhe em branch e abra PR. Não faça merge sem o OK do Geovane.
- Nunca commite segredos nem `.env`.
